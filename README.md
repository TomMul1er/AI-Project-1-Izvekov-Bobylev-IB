# AI-Project №1 Izvekov-Bobylev (IB)  

Тема: Предсказание качества воздуха  
Куратор: Денис Бобылев  
Состав: Георгий Извеков  
    
**План работы:**  
  
**Чекпойнт 1: Старт и планирование**  

  Знакомство с куратором  
  Фиксация темы и создание репозитория  
    
**Чекпойнт 2: Разведочный анализ данных (EDA)**  

  Выбор целевого региона для анализа  
  Сбор актуальных и исторических данных  
  Анализ собранных данных, выявление аномалий, выбросов  
    
**Чекпойнт 3: Первые ML-модели**  

  Выбор метрик валидации (MAE, RMSE, WAPE) с учетом специфики временных рядов  
  Построение Baseline модели  
  Обучение классических ML-моделей (вероятно линейная регрессия)  
    
**Чекпойнт 4: ML-сервис на FastAPI**  
  
  Упаковка лучшей ML-модели  
  Разработка API для инференса модели  
    
**Промежуточная защита проекта:**  
    
**Чекпойнт 5: Улучшение ML-модели**   
   
  Поиск и добавление новых признаков признаков  
  Построение нелинейных моделей и внедрение этих моделей  
    
**Чекпойнт 6: Нейронные сети**  
  
  Применение архитектур для временных рядов  
  Сравнение результатов DL подходов с классическим ML  
    
**Чекпойнт 7: Финальные доработки и MLOps**  
  
  Интеграция MLflow для трекинга экспериментов и логирования моделей  
  Проверка модели на устойчивость и анализ ошибок
